# Scenic journey v1 — Aluminé to the sea

Objective: a browser game where an inflatable raft drifts the real route Río Aluminé → Collón Curá → Limay → Negro → Atlantic, stylized 3D, relaxed (no hazards). Rapids/physics are a later feature (v2), not in this document.
Branch: `feat/scenic-journey-v1` (local repo, no remote yet). Delivery strategy: `ask-on-risk`; forecast far above 400 changed lines, so the PR chain strategy is asked once a remote exists.
Runners: `pnpm test` (vitest) for `src/`, `.venv/bin/pytest tools/` for the pipeline. Stack: Vite + TypeScript + Three.js; pipeline in Python (rasterio allowed, project-local `.venv`).

## Specs

- **S1 Route.** "an embarcation going from river alumine, passing rio collon cura, limay, rio negro until it reachs the sea". The route is the HydroRIVERS main stem `MAIN_RIV = 61560077`, walked by `NEXT_DOWN` from reach `61546168` (Lago Aluminé outlet, −71.06/−38.96) to `61560077` (`NEXT_DOWN = 0`, mouth −62.802/−40.994): 371 reaches, 1,292.8 km. River names per reach come from `basin-explorer/data/out/nqn/reaches.ndjson` (`river` ∈ `alumine`, `collon-cura`, `limay`, `negro`). Acceptance: the stitched route is one ordered polyline, strictly decreasing `distanceToSeaKm`, four named segments in that order, ends at the sea.
- **S2 Real-ish geography.** "Real-ish path from map data … Recognizable landmarks, real proportions (compressed in length)". Full trip "About 30 minutes": ~32 km of game river at ~18 m/s. Compression is anisotropic (see L3): along-route 1:40, river width set for playability, valley cross-section and heights at their own scales. Acceptance: bends, reservoirs, dams and towns appear in real order at proportional positions along the route.
- **S3 Look.** "Graphics 3d-like, cartoon but realistic, not satellite. Something like this: https://matajuegos.itch.io/atuel". No satellite/aerial imagery as texture. Toon/gradient shading, stylized water, fog, sky, instanced vegetation, biomes by stretch: Andean forest with araucarias (Aluminé) → steppe canyons (Collón Curá, Limay) → reservoirs → irrigated Río Negro valley with poplars/orchards → estuary and sea.
- **S4 Boat.** "Inflatable raft". The raft follows the current along the route, with gentle left/right steering inside the channel; it cannot leave the river, sink or get stuck. Keyboard (A/D, arrows) and touch.
- **S5 Gameplay v1.** "first Relaxed scenic journey, then Raft/kayak physics + rapids + obstacles". v1 has no damage, timer or fail state. It ends when the raft reaches the sea, with an ending screen.
- **S6 Reservoirs and dams.** On-route reservoirs: Piedra del Águila, Pichi Picún Leufú, El Chocón (Embalse Ezequiel Ramos Mexía), Arroyito. Alicurá is upstream of the Collón Curá junction and is not on the route. Water widens into a lake; at each dam wall the game does a short fade "portage" to the river below. (Assumption: portage by fade is the planner's choice, not a user request.)
- **S7 Text and language.** "Spanish + English", switchable. HUD shows current river name, progress along the route, and landmark notes (towns, dams, confluences) from `basin-explorer/data/work/nqn/localities/nodes.ndjson` and `tiles/ign_dam_walls.geojson`. Strings live in one file per language.
- **S8 Platform.** "Three.js (web)". Static build that runs from a plain file server and can be zipped for itch.io HTML5. Target 60 fps on a mid laptop; usable on a phone.
- **S9 Data hygiene.** basin-explorer is read-only: never write inside it. Derived game data is committed under `public/data/`; downloaded rasters stay in `data/raw/` (git-ignored). Do not use the `*_CPA.zip` files (Córdoba only).
